# 失败模式清单（W2 产出）

> 从 `docs/链路风险表.md` 第四节派生。要求：每条都写"看着对但其实是错"的那种，不要写"报错/崩溃"。

## 格式（每类一条，按这个填）

```
### F-编号 名称
- 现象：用户看到的是什么
- 触发条件：
- 真实案例（来源：____，日期 ____）
- 怎么发现（断言 / 观测字段 / 抽检方式）
- 归因层：输入 / 路由 / 检索 / 上下文 / 生成 / 工具 / 策略 / 评测口径
- 优先级：P0 必须拦 / P1 应该拦 / P2 记录即可
- 对应用例ID：____
```
